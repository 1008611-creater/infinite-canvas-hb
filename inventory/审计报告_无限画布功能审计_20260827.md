## 4. 两个"没跑通"的点（都是配置/装配，不是 bug）

### ⚠️ 1. 画布默认通道指向 `https://api.openai.com`（最大坑）
`use-config-store.ts:67` `OPENAI_BASE_URL = "https://api.openai.com"`，且默认 `apiKey=""`。
→ 第一次点"视频生成"若没先配置通道，会请求 OpenAI 报 401。
**处理**：在画布 `/config` 新增一个视频通道：Base URL=`http://localhost:8787`，Key 任意非空占位，选 `agnes-video-2.5-flash`，存为默认视频模型。**这一步是使用前置，不是功能缺失。**

### ⚠️ 2. canvas-agent 本地仓库版需先 build
`dist/` 未生成（`npm run build` 后才有）。`npx -y` 版走 npm 预编译包不受影响。

## 6. 使用前置清单（让功能真正"跑通"）

1. 服务在线：`launcher/start.bat`（或已手动起的 3000+8787）。
2. 浏览器开 `http://localhost:3000`。
3. `/config` 建视频通道：Base URL=`http://localhost:8787`，Key 任意，模型刷出后设默认视频模型。
4. （可选）本地启 Agent：`npx -y @basketikun/canvas-agent`，画布右上角填入 地址+token。
5. 实测画布：拖图→连线到视频节点→生成。
