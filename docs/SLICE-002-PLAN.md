## 静态基线（2026-09-21 只读核实）

本轮**没有改动任何权威源码**，以下是写计划所依据的实测事实：

- 三站同机同 Caddy（`deeptutor-public-caddy`，占宿主 80/443），Caddyfile 中 `hb` 与 `apic` 声明为 `http://`（TLS 由隧道终止），`sd2` 由 Caddy 自己终止 TLS。**这是 2026-09-19 踩过的坑：写成 HTTPS 站会 308 循环。**
- 统一入口域名不存在：`auth.cauai.fun` / `login.cauai.fun` / `one.cauai.fun` 均 NXDOMAIN。
- `cauai.fun` 顶级域名与 `www` 当前解析到 Vercel（`vercel-dns`），承载的是个人作品集站点（页面标题实测为「刘曙宾 - AI 产品与智能工作台作品集」）。**不在本切片范围内。**
- `apic` 的 New API 版本 `v1.0.0-rc.38`，仅绑定 `127.0.0.1:13020`，未直接暴露公网端口。
- 三套密码哈希互不兼容（bcryptjs / scrypt + 独立盐列 / Go 自有），已在 §1 逐条取证。
- New API 是 OIDC **客户端**不是提供方，已在 §1 取证（官方仓库 `setting/system_setting/oidc.go`）。
- `hb` 门禁 cookie 名为 `canvas_auth`（`deploy/nginx-docker.conf` L12/L14）；`hb` 应用会话 cookie 是 `SESSION_COOKIE`；`sd2` 会话 cookie 是 `niannian_session`（`lib/auth.ts` L1074）。**三者是三个不同的东西，不能混为一谈。**
- `sd2` 自有铁律见 `sd2/AGENTS.md`：禁止硬编码 `zy_model_*`；下单即预扣、终态结算、失败退款；每次流水写 `credit_ledger` 可追溯 `job_id`；禁止 mock 冒充真实生成；Postgres 为唯一业务库；`npm run verify` 是唯一验收入口。

以上不是「方案已定」的结论。§4.2 与 §4.3 的技术选型需要 owner 裁决，裁决结果记入 `docs/DECISIONS.md`。
