# 产品章程 · 无限画布

## 一句话

无限画布（https://hb.cauai.fun）是一个**面向 AI 视频内容生产的节点式画布工作台**：把剧本、角色与场景资产、分镜、抽卡、成片串在一条可拖拽的连线上，用视频模型出片。

## 是什么

- **视频工作台**。核心动作是"在画布上组织内容生产链，然后调用视频模型出片"。
- **MIT 开源项目的二次开发**。上游 `basketikun/infinite-canvas`，本 fork 自述定位为"天宫漫剧工作台"。
- **浏览器本地优先**。业务数据默认存在本机 IndexedDB；需要跨设备才启用 WebDAV 云同步。
- **公开售卖工具**。[用户确认，2026-09-27] HB 面向外部用户销售；当前站点密码门禁属于过渡性访问控制，不能替代账号、额度和权限体系。
- **天宫漫剧内容生产的画布层**。它是生产线的一环，不是内容本身。

## 不是什么

- **不是通用白板 / 不是 Figma / 不是 Miro。** 节点类型、连线语义、执行链都是为视频生产设计的，不是自由图形编辑工具。
- **不是念念 Studio 画布（`ai.cauai.fun/studio/`）。** 那是另一个产品、另一套源码、另一套账本。两者目前未发现技术关系。
- **面向公开售卖，但尚未达到可对外承诺的稳定收费能力。** 截至 2026-09-18：注册保持公开并已启用邮箱验证码；计费层已落地并发布到线上，免费试拍已关闭，紫域入口仍保留门禁。
  但真实收费闭环仍不能宣称完全验收：插件卸载还原、节点链真实浏览器执行、真库并发幂等及结果长期落盘仍有独立验证边界。三批次路线见 `implementation/deploy/ACCEPTANCE.md`，收益结构见 `REVENUE_MODEL.md`。
  在这些验收边界收口前，对外口径仍是"私有工具/内部试运行"，不得宣传已稳定收费。
- **不是内容仓库。** 成片、抽卡结果、素材原始文件不进本文件夹。
- **不是可构建的源码仓。** 本文件夹不跑构建，源码在权威目录。

## 它服务于谁

**主要用户：AI 视频创作者和内容团队。** 当前重点工作流是天宫漫剧：

- 主角设定：柳小念；只做上/中/下三集，不铺第二季
- 画布命名前缀：`[剧本]`、`[资产·角色]`、`[资产·场景]`、`[分镜]`、`[抽卡]`、`[验收]`、`[阻塞]`、`[复盘]`
- 连线语义：剧本 → 资产 → 分镜 → 抽卡 → 验收

**潜在用户：同类 AI 视频创作者。** 这是收益模型里唯一现实的方向。
目前**尚未达到可对外承诺的稳定收费能力**——收费代码已落地并发布，真实注册与未登录资金入口已验证；但完整收费验收仍受节点链真实执行、真库并发幂等、结果长期落盘等证据边界约束。
在批次 1 通过验收（`ACCEPTANCE.md` A-00 ~ A-12）之前，不得按"已能收费"对外表述。

## 视觉 DNA（天宫漫剧的硬约束）

画布上产出的画面必须守住这套约束，否则整个产品线的输出不一致：

- **要**：中式天宫巨构（朱红立柱、斗拱、金瓦、汉白玉、圆月洞门、天瀑、金色云海）；人物修长清俊、长袍轻纱、侧脸/背影/逆光、渺小超然；电影级 3D 国漫、HDR、冷暖对撞、体积雾、Bloom。
- **不要**：欧美写实战争风、塑料 CGI、网红妆、正面特写定妆照式。
- **已知边界**：文生视频模式不用于正式镜头。没有底图兜底时画面会冒出具体的牌匾文字，属于模型缺陷而非提示词问题。正式镜头走首尾帧模式，先用高质量出图工具做首尾帧。

## 事实分层（内容侧纪律）

画布上每个关键节点的内容必须标注来源层级，避免把推测当史实：

| 标注 | 含义 |
|---|---|
| `source_fact` | 有据可查的事实 |
| `adaptation` | 基于事实的改编 |
| `影视化补强` | 为画面效果做的补强，非事实 |
| `unverified` | 未核实，待查 |

## 能力分级

用 L1–L4 描述画布能力的成熟度，避免把"能点开"说成"能用"：

| 级别 | 定义 | 当前落点 |
|---|---|---|
| **L1 可见** | 页面能打开、路由能加载、界面元素存在 | 8/8 路由已达成 |
| **L2 可点** | 真实浏览器里交互可用（拖拽、连线、缩放、节点执行） | **部分验证**：拖拽 / 连线 / 缩放 / 参数钳位 / 插件安装已有真实浏览器证据；**节点链真实执行、插件卸载还原仍未完成**（见 `docs/STATUS_20260913_L2_EVIDENCE.md`） |
| **L3 可出片** | 端到端跑通并产出可用的成片 | 视频链已达成（2026-09-01 有记录） |
| **L4 可生产** | 稳定、可重复、可计费地支撑日常生产 | 未达成（计费层设计稿已完成，见 `implementation/`） |

L1 的 8 条路由实测数据见 `inventory/审计报告_无限画布功能审计_20260827.md`。

**L2 最新口径（2026-09-18）**：真实浏览器已验证拖拽、连线（含反向/去重/撤销）、缩放、模式适配、秒数钳位、官方插件列表和按 URL 安装第三方插件。**节点链真实执行与插件卸载还原仍未验证**；真实出片会消耗额度，不在本轮擅自执行。完整证据见 `docs/STATUS_20260913_L2_EVIDENCE.md`。

> ★ **顺序风险（不许省略）**：计费层（L4）的**设计**先于 L2 验证完成，
> 也就是说我们是在"画布能不能点得动"尚未验证的前提下先建收款能力的。
> 批次 1 上线前**必须**补一次真实浏览器冒烟（`ACCEPTANCE.md` A-18），
> 否则可能出现"能收钱但点不动"。

## 用户必答五问

任何对画布的功能改动，动手前先答清楚：

1. **谁用？** 自己，还是外部创作者？
2. **哪个环节？** 剧本 / 资产 / 分镜 / 抽卡 / 验收，具体哪一步？
3. **替代了什么？** 现在这一步是怎么做的，改完之后少做什么？
4. **出片质量受影响吗？** 会不会破坏视觉 DNA 或事实分层？
5. **花谁的钱？** 免费额度还是付费模型？付费的话授权了吗？

答不上来的需求不进路线图。
