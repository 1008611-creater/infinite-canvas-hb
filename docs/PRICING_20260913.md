## 三、★ 毛利表（本节是你要核对的核心）

### 3.1 一条公式

```
毛利率 = 1 − (每紫域积分采购价 ÷ ¥0.15)
盈亏平衡点：每紫域积分采购价 = ¥0.15
```

推导：用户为每个紫域积分付 ¥0.15（= 1.5 × ¥0.10）。所以**只要你的积分采购价低于 ¥0.15，每一单都赚钱**；高于 ¥0.15 就是卖一单亏一单。

### 3.2 按采购价的敏感度

| 1 紫域积分采购价 | 相当于 | 毛利率 | 判定 |
|---|---|---|---|
| ¥0.01 | ¥1 = 100 积分 | **93.3%** | 很健康 |
| ¥0.02 | ¥1 = 50 积分 | 86.7% | 健康 |
| ¥0.03 | ¥1 = 33 积分 | 80.0% | 健康 |
| ¥0.05 | ¥1 = 20 积分 | 66.7% | 可接受 |
| ¥0.06 | ¥1 = 16.7 积分 | 60.0% | 可接受 |
| ¥0.10 | ¥1 = 10 积分 | 33.3% | 偏薄，建议提倍率 |
| ¥0.12 | ¥1 = 8.3 积分 | 20.0% | 很薄 |
| ¥0.15 | ¥1 = 6.7 积分 | 0% | **盈亏平衡，不能再高** |

### 3.4 我要问你的唯一一个数

> **你买 1 个紫域积分实际花了多少钱？**（或者说：充 ¥100 到账多少积分？）

我已从紫域主站前端公开代码查到官方换算口径 **100 积分 = ¥1.00（¥0.01/积分）**，所以上表按 93.3% 毛利算。
但那是**官方标价**，不是你实际到手价——如果你走的是折扣渠道或大额充值，实际单价可能更低（更赚）；
如果紫域对代理商另有加价，则可能更高。这个数我查不到（充值页对外 404，只有登录后的主站才有），只能由你确认。

**敏感度**：¥0.01 → 93.3% ｜ ¥0.03 → 80% ｜ ¥0.05 → 66.7% ｜ ¥0.10 → 33.3% ｜ ¥0.15 → 0%（盈亏平衡）。

**如果实际采购价高于 ¥0.10**，建议把倍率从 1.5 提到 2.0 或 2.5（改 `credits.js` 顶部一个常量即可），否则 4K/1080p 这类大单会把利润吃光。

## 七、失败任务怎么处置（口径已实测订正）

**实测样本 19/19：失败任务全部 `refunded=true` 且 `refundAmount == cost`，0 例外。**

样本覆盖 7 个 cost 档（0 / 5 / 200 / 300 / 350 / 380 / 450），明细见 `docs/STATUS_20260913.md` §2.2。

| cost | 失败任务数 | refunded | refundAmount |
|---|---|---|---|
| 0 | 3 | true | 0 |
| 5 | 4 | true | 5 |
| 200 | 6 | true | 200 |
| 300 | 1 | true | 300 |
| 350 | 2 | true | 350 |
| 380 | 2 | true | 380 |
| 450 | 1 | true | 450 |

聚合：失败任务名义扣费合计 3430 积分，实际退款 3430 积分，**净支出 0 积分（19/19 全退）**。`failed && refundAmount != cost` **命中 0 行**。

**但代码里仍然不假设"必退"**：一律读 `refunded` / `refundAmount` 对账。

- `refunded=true` → 按 `refundAmount` 全额退回用户点数
- `refunded=false` 且 `cost>0` → **照常扣用户点数**（成本已经发生）
- `cost=0` → 不扣不退

紫域官方文档原文：*「提交成功会立即扣除对应额度；如果任务最终失败，系统会按现有规则返还额度」* —— **"按现有规则"就是不可依赖的意思，所以必须读字段。**

## 八、结算口径（预扣 → 结算）

```
1. 提交前预扣：estimate = costPerSecond > 0 ? costPerSecond × 秒数 : cost
   换算成点数预扣；余额不足 → 直接拒绝，不提交紫域
2. 紫域返回 job.cost（真实值）
3. 结算：预扣额 vs ceil(job.cost × 1.5) 的差额，多退少补
```

**为什么不能只信目录里的 `cost`**：实测 `zy_model_2db335ab16705b6ffb21` 目录写 `cost=200 / costPerSecond=50`，跑 30 秒**实际扣 1500**。目录的 `cost` 是"起步价"不是"成交价"。

**为什么不用 `durationCosts`**：实测 **44/44 全部为空 `{}`**，不可依赖。
