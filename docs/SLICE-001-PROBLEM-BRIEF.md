# 垂直切片 001 · Problem Brief

> 状态：G3 已获 owner 批准；已完成第一处链路修复，真实浏览器执行与发布仍待 G4/G5/G6。

## 问题

现有证据证明画布可以创建节点、拖拽连线和调整参数，但没有证明一条真实的多节点链能从输入走到视频结果。当前最大的产品风险是：用户看到“连上了”，却无法稳定执行、无法知道失败原因，或结果没有长期落盘。

## 目标用户

使用无限画布组织 AI 视频生产链的创作者。第一刀只验证“一个输入素材节点 → 一个视频节点”的最小闭环，不代表三集内容生产已经完成。

## 本次目标

在授权的测试账号和受控额度下，证明一条真实链路能够：

1. 打开已有项目并读取节点与连线。
2. 使用一个已有图片素材作为输入，连接到视频节点。
3. 提交一次视频任务，并显示可追踪的任务状态。
4. 成功时把结果保存为画布可引用的媒体记录。
5. 失败时显示可理解的错误，避免留下假成功、永久 loading 或重复扣费。

## 明确不做

- 不在本切片合并上游版本或重写全站。
- 不做三集内容、Agent、插件卸载还原或 WebDAV 重构。
- 不在没有单独书面授权时消耗真实额度。
- 不把“接口返回 200”或“节点连线存在”当成执行成功。

## Owner 与闸门

- Owner：项目 owner（待确认）。
- G3：确认测试账号、额度上限、允许的模型、回滚方式和执行时间。
- G4：真实主流程和至少一条错误路径都有落盘证据。
- G5：独立 review 的 blocking = 0。
- G6：只在发布记录、回滚和冒烟验证齐全后允许发布。
