## 7. 插件沙箱契约（`web/src/services/api/model-plugin.ts`）

`new Function`（L119）的形参顺序**逐字确认**，共 15 个：

```
prompt, images, messages, params, model, baseUrl, apiKey, systemPrompt,
reasoningEffort, http, request, poll, sleep, signal, onDelta
```

写紫域渠道 `script` 时**只能用这些变量名**，用错会直接 ReferenceError。

| 工具 | 行为 |
|---|---|
| `http.post/get(path, body, opts)` | 经 `pluginUrl(config, path)` 拼 baseUrl，**自动注入 `Authorization: Bearer ${config.apiKey}`** |
| `request(config)` | **裸 axios**：`{...requestConfig, url: pluginUrl(config, url)}` —— **不自动注入 Authorization**，method/url/headers/body 全由脚本自己控制 |
| `poll(request, extract, options)` | `intervalMs = options?.intervalMs ?? 2500`；`timeoutMs = options?.timeoutMs ?? 300000`。`extract` 返回 `null/undefined/false` 继续轮询，否则返回 |

**关键推论**：渠道模板里 `apiKey` 是空串，所以走 `http.*` 会发出 `Authorization: Bearer `（空）。
紫域的鉴权必须由 **nginx 在服务端注入**，脚本侧用 `request()` 或让 nginx 覆盖该头。
